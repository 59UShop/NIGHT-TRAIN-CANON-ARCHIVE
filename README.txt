夜汽車 Archive v1.5

正史資料 v2.7 を基準にしたローカルArchiveです。

v0.8.1 主な更新:
- スマホ縦画面でハンバーガーメニューが消えるCSS競合を修正
- モバイルメニューに背景タップで閉じるスクリーンと閉じるボタンを追加
- 「施設・場所・路線」メニューを「用語集」へ統一
- 「作画資料 / VISUAL DEVELOPMENT」ページを新設
- キャラクターデザイン進捗（未着手→ラフ→デザイン確定→三面図→作画資料完成）を管理可能
- 本文上の外見確定情報と作者デザイン／検討案を分離表示
- 身長比較ボードを追加。数値未定のままでも運用可能
- 人物詳細の ART GUIDE を VISUAL DEV へ拡張

正史設定そのものへの追加・変更はありません。

使い方:
1. ZIPを解凍
2. index.htmlをダブルクリック

外部ライブラリ・サーバー不要です。


=== v0.8.1 UI整理 ===

- ビジュアル進捗や身長比較から人物詳細を開いた場合、戻ると元のサブ画面へ戻る。


=== v0.9 SCENE CHECK ===
- サイドメニューは増やさず、「時系列」の中へ SCENE CHECK を統合。
- 時点／人物／場所を選んで、関係性・既知情報・舞台状態・重要アイテム・連続性警告を確認可能。
- 初期チェックポイント：MAIN DAY1 / DAY2 / DAY3 / DAY4 4:44 / 第一部終幕 / DAY5 / DAY11現在、DAILY1 / 25–30 / 31 / 32–35 / 49–55。
- 「未登録＝存在しない／知らない」ではない旨をUI内に明示。
- CHECK NOTE をクリップボードへコピー可能（非対応環境では手動コピー表示）。
- 正史設定そのものへの追加・変更はありません。制作支援用データです。
