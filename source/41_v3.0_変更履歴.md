# 正史資料 v3.0 変更履歴

## 大分類

日常・恋愛編を完成第一部エピローグ翌朝から全面再構成するためのメジャー更新。

## 主な変更

- 旧日常編DAY時系列を正史現在から撤去し、イベント素材プール化。
- リーナ×ノアの旧「交際済み」を撤去。最終ペアは維持し、恋愛を仲間状態から超スローで再構成。
- リーナ24歳、ノア27歳、レナード34歳、ガレス58歳前後を確定。
- リーナ両親クララ／エリオットを新規確定。両親は健在。
- リーナの前職を小さな食堂のホール兼調理補助に確定。
- リーナ幼少期、2歳頃までルーナベル／夜汽車表店へ頻繁に来ていた設定を追加。
- エレノア夫・クララ幼少期・ガレスとの古い関係を追加。
- 完成小説優先でエレノア外界3か月／忘却線約17年を確定。旧3日を廃止。
- ヴァルグレン家、兄レナード、ノア12歳家出の原因を確定。
- レナードが現在手紙を送る理由＝家督継承直前を確定。
- ガレス・ハイデル＝王国騎士団長、ノアの師、エレノア長年の恋愛相手を追加。
- 《王国騎士団》の軽量組織構造・任務・ノア勤務を確定。
- カイルを善良なリーナ好意騎士として再配置。
- ヴィオラを後期リーナ嫉妬導線として保持。
- 帰還者の身分整備ルートを追加。エマの冒険者登録は不要、ミアは登録済み。
- 《夜汽車》通常営業8:00〜21:00、週1店休日、夜間受入分離を確定。
- 店主居住区は日常編序盤に改めて発見。ノア2階選択イベントを再演。
- トキは日常編翌朝が初対面。「みゃあ」、白＋夜空の耳先／尻尾へ統一。
- 商品開発を「結果は固定、過程は再演」へ整理。
- 紙月堂＝アレン実家を確定。
- ミア／ユアンの直接再会を日常編へ移し、最初の連絡から描く。
- 第二部用謎を日常・恋愛編から明確に隔離。
