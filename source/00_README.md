## v1.0で正式決定した主要事項

- 作品全体の正式タイトルは **『夜汽車』**。総称は「夜汽車シリーズ」。
- 《月の心臓》は**同一の主装置が時代によって移設された**ものとして統合。
  - 109年前：涯月駅
  - 23年前：アルカ中央魔導院地下
  - 現在：涯月駅
  - 23年前以後に涯月駅へ戻った具体的な経緯は、現時点では記録欠落／今後の伏線。
- アルカは **《魔導都市国家アルカ》**。
  - 一つの巨大都市そのものが国家に近い都市国家。
  - 中央魔導院が学術・行政の中枢を担う。
  - 《アルカ消失》では中央魔導院を含む中枢市街が大規模時間異常へ飲み込まれた。
  - 外縁部・国外滞在者・避難者まで全員消えたわけではない。
  - 第一部で人々は救出されたが、**都市国家そのものが丸ごと現代へ完全復帰したとはしない**。
- 蒼い月の弱体化は削除せず、**月の心臓／星海線に連なる第二部以降の伏線**として残す。
- フィンは **77年前組ではなく23年前《アルカ消失》組**。
- マレーナは **77年前のベルネ側《夜汽車》の正式店主**であり、同時に宿兼食堂《銀樹亭》を営んでいた。現ルーナベル表店とは別拠点で、《銀樹亭》そのものが入口だったかは未確定。
- リゼの現代所属は **ルーナベル王立魔導院**。アルカ中央魔導院とは別組織。
- ユアンとは **まだ直接再会していない**。現在はヴァルド公国への照会・連絡を進める段階。

## 正史ラベル

- **【確定】**：後期の明示設定、ユーザーによる修正、複数回の描写などから現在の正史として扱ってよい。
- **【暫定】**：作中で示されているが、詳細・名称・他設定との接続に追加確認が必要。
- **【未確定】**：存在や方向性は示唆されているが、内容をまだ決めていない。
- **【旧設定／不採用】**：後から明確に撤回・修正され、今後そのまま再利用しない。

## 採用優先順位

1. ユーザーが後から明示的に修正した内容
2. 後期ログに持ち込まれた統合設定資料
3. 後期ログで複数回維持された作中描写
4. 初期ログの単発描写
5. アシスタント側の提案・推測

5は、ユーザーが明示的に採用していない限り正史へ昇格させない。

## 3層構造

### Canon / 正史設定集
「この世界では何が真実か」を管理する辞書。

### Timeline / 時系列
「何が、いつ起きたか」を管理する履歴。

### Save State / セーブデータ
「ゲームが今どこまで進んでいるか」を管理する現在状態。

## シリーズの切り分け

- **本編**：夜汽車の事件・時間異常・帰れなかった人々・《帰属》を軸にする長編。
- **日常編**：事件後の店・駅・宿泊客・商品開発・仲間の生活・恋愛を軸にする別シリーズ。
- 世界設定は共通正史。ただし、本編DAYと日常編DAYは別カウンタとして扱う。

## ゲーム再開／小説化時の制作ルール

**【確定・制作ルール】**

- キャラクターが「第一部」「イベント」「ルート」など作品外メタ用語を口にしない。
- 地の文を単語・短文単位で連続改行する「コマ切れ文体」は使わない。
- 見せ場でも普通の小説文・段落を維持する。
- 不明設定をその場で補完しない。
- 恋愛対象は男性。女性キャラクターとは親密な友情を描ける。
- セイルとルチアの既存の特別な関係は崩さず、リーナの恋愛ルートへ横滑りさせない。
