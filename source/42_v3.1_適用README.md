## 正史化ルール

- ユーザーが「採用」「それでいこう」「固定」等と明示承認した提案は正史。
- アシスタント提案だけで未承認のものは正史化しない。
- ゲームログ内で発生した出来事は、後から却下・訂正されない限り進行済みイベント。
- 未確定の穴は埋めない。
- 将来案・有力展開と、既に起きた事実を分離する。
