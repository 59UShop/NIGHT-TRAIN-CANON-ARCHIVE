# 1. 日常・恋愛編の再構成方針

## 1.1 開始地点

- 【作者確定】日常・恋愛編は **完成第一部エピローグの翌朝**から開始する。
- 【作者確定】旧日常編の DAY 番号は引き継がない。
- 【運用基準】暦は第一部開始を王国暦724年・秋月3日とし、再構成版の日常編開始は **秋月8日朝相当**を基準とする。完成小説／エピローグとの日付校正を優先し、旧「春開始」表記は破棄する。
- 【作者確定】開始時点で表の喫茶店はまだ本格通常営業に戻りきっていない。帰還者の生活整備、宿泊棟、駅、店の再始動を日常編で描く。

## 1.2 旧日常編の扱い

旧日常編は「過去にすべて起きた正史」ではなく、以下の4分類で扱う。

1. 完成第一部・作者確定と一致するもの → 正史として保持
2. 最終的な商品・施設・人物結果は採用するが、イベント発生過程は再演するもの
3. 未完サブストーリーとして再構成版へ持ち込むもの
4. 旧設定／矛盾／進行が速すぎるため破棄するもの

### 破棄する旧進行

- DAY1〜55という連番時系列
- 春開始→夏という絶対季節接続
- リーナ×ノアが短期間で交際・キス・宿泊・濃いカップル生活へ進む旧速度
- DAY31〜33付近で告白・交際が確定する旧流れ
- 旧セーブ `daily_day:55` を「現在」とする扱い

### イベント素材として保持するもの

- 商品開発（夜汽車の窓／旅支度セット／ほしねこクッキー／今日の旅切符／紙箱／特別缶／月蜜草等）
- アレンと紙月堂
- カイル、ヴィオラ
- 灯鐘町、玻璃庭園、宵火市等の外出先
- 日常の買い出し、季節メニュー、普通の客、外出・小旅行

ただし、これらは「いつ起きるか」を固定せず、再構成版の日常の流れに合わせて発生させる。

### エレノアとの出会い

- 【作者確定】若手騎士時代、任務帰りに腕を負傷し、先輩騎士に連れられて《夜汽車》へ来たのが最初の接触。
- リーナ第一部DAY1のノアも腕を負傷して店へ来るため、「エレノアとリーナ、それぞれの店主時代に負傷した騎士が初期から店へ入り込む」対比として扱える。
- 最初から恋愛ではなく、店主と気の強い若手常連として口喧嘩の多い関係。
- やがて友人・常連として時間を重ね、ガレス側が恋愛感情を自覚する。
- ガレスは、亡き夫の存在を否定・上書きしない。エレノアが今も夫を愛していることを理解したうえで、別の問題としてエレノアを愛している。
- 長年、冗談めいた表面も含む求婚・誘いを続けているが、エレノアが断れば引く。境界線は守る。
- 【作者固定・未発生】第一部後、エレノアが店主を退いたあと、ガレスからの食事の誘いに初めて「一度くらいなら」と応じる重要イベントを日常編で描く。
- その理由の核は **「私、もう店主じゃないもの」**。亡夫を忘れたからではなく、店主責任をリーナへ渡し、初めて自分のための時間を許すから。
- 一度の食事＝即交際・再婚とはしない。その後は物語の中で動かす。

- 【作者確定】ガレスはクララの幼少期から知っており、クララにとって当初は怖い大柄な若手騎士、後に「ガレスおじちゃん」に近い家族ぐるみの古参知人となる。

### 日常編初登場

- 【作者固定・未発生】日常編序盤、エレノア帰還の報を聞いて王都からルーナベルへ来る。

# 6. 王国騎士団

## 6.1 組織

- 【作者確定】正式組織名：**《王国騎士団》**。
- 王国直属の公共騎士組織。戦争専用軍ではなく、街道・都市治安、魔物・犯罪対応、事故・災害救助、要人護衛、捜索、地域非常対応、行政支援等を担う。
- 大枠：
  1. 王都総本部（騎士団長・全国調整）
  2. 地方本部（ルーナベル地方本部等）
  3. 各地の詰所（巡回・住民対応）
- 指揮役職として、騎士団長／副団長／地方本部長／隊長／副隊長等を置ける。
- 一般団員は正騎士／見習い騎士程度の区分でよい。過度な軍事官僚制にはしない。
- 外国人も、身元確認・王国への服務誓約・推薦／試験等を経れば加入可能。ヴァルド出身のノアも正規加入。

## 6.2 ノアの現在勤務

- 【作者確定】ノアはルーナベル地方本部所属の中堅 **正騎士**。隊長等の管理職にはしない。
- 小規模現場では後輩を連れて動ける経験はある。
- 交代勤務。朝〜夕の日勤、遅番、夜間巡回、非常招集等があり、固定曜日休みではない。
