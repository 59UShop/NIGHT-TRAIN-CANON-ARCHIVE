夜汽車 Archive v0.4 / 施設イメージ画像

MAPで施設をクリックしたときの右側プレビュー画像をここへ置けます。
画像が存在しない場合は自動でプレースホルダー表示になります。

推奨: PNG/JPG/WebP、16:9〜3:2程度。
ファイル名は data/maps.js の image フィールドに対応します。

例:
  cafe-counter.png
  kitchen.png
  station-platform.png
  courtyard.png
  greenhouse.png
  library.png
  residence-living.png
  reena-room.png

後からファイル名を変えたい場合は data/maps.js / maps.json の image を変更してください。
