人物画像の差し替え方法
====================

このフォルダに、data/character-config.js で指定されているファイル名の PNG を置くと、
人物一覧と人物詳細画面へ自動反映されます。画像がない人物は装飾付きプレースホルダー表示になります。

推奨: 縦長 4:5～2:3 / 1200px以上 / 背景透過PNGでも可。
切り抜き位置は data/character-config.js の objectPosition で人物ごとに調整できます。
